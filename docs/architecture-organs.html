🧱 Buttons Bebe — LEGO Organs

Think of the help desk as a body made of LEGO organs. Each organ does one job. Wires carry messages between organs. Green bricks only look, orange bricks need a human, red bricks are locked off. Click any organ for details.

🟩 look-only🟧 human-only🟥 locked / retiredclick an organ 👆
One ticket's journey (follow the wires):
  1. 📬 Mailbox (Gorgias) gets a customer message → knocks on the Front Door.
  2. 🚪 Front Door (:8000) checks the secret handshake, writes the job on a sticky note (SQLite queue).
  3. 🧠 Brain picks up one sticky note, asks three Library organs for facts, writes a draft letter. Never sends.
  4. 👀 Review Desk shows the draft to a human, who clicks Send, Note, or Rewrite — the only way anything goes out.
  5. 📝 Memory saves approved replies so future drafts get smarter. 🔔 Alarm taps the owner for urgent tickets.
