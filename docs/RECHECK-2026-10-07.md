# Recheck — architecture review and SaaS path (2026-10-07)

Branch `recheck` (same commit as `main` / `origin/main`, 5ad51bf). Read-only review:
six parallel research agents (pipeline, frontends, KB/tools/integrations,
deploy/ops/security, second helpdesk, SaaS market) plus manual spot-checks of every
high-severity claim. Scratchpad: tldraw canvas `6558535a`. Nothing touched production.

**Bottom line.** The core idea is sound and several modules are genuinely good
(human-confirmed durable sends, token-authenticated model output, staged KB index,
eval suite). But the system is a single-merchant VPS installation, not a product:
tenancy, identity, config, KB, prompts and ops all assume one store on one box, the
docs disagree with the code in places that matter, and ~26% of the repo is retired
code. Do not retrofit tenancy into this tree. Fix the live security items now, cut the
dead weight, then build a multi-tenant core that ports the good modules, with
Buttons Bebe as tenant #1.

## 3. Bad architecture

1. **Production box doubles as dev box.** Source checkout and Surge on the VPS, public Hermes dashboard, 3 unrelated apps (warehouse, exchange, receiving), 17/19 units as root. One failure domain holding every credential.
2. **Processor concurrency = 1.** One synchronous Hermes CLI run at a time inside an async loop (~50 s/run → ≤70/h; worst case 14.5 min per message). The reconcile task stalls during runs. Fix: `asyncio.create_subprocess_exec` + a lease column on `job_queue` + N workers.
3. **webhook and processor are one codebase posing as two packages.** 13 cross-imports via `sys.path` edits and systemd `PYTHONPATH`; behaviour depends on import order (`rewrite_runner.py:10-17`). The HTTP result POST (`orchestrator.py:145-225`) is a pass-through to a function the processor already calls directly. Fix: one `bb_core` package, two entrypoints.
4. **Copy-paste integration layer.** 4 Shopify token mints/clients with 4 different read-only enforcement schemes (one regex gate is bypassable by a fragment-plus-mutation document — latent, constant documents today), 6+ Gorgias clients, 3 hand-rolled MCP JSON-RPC clients, 5+ `.env` loaders, the toolset triple spelled in 7 places. Fix: one `providers/` package.
5. **AI draft → Inbox via a 60 s full-window re-export** that reads the webhook's private tables (`console-src/inbox/export_projection.py`); a webhook schema change breaks the Inbox silently. Fix: a loopback read-only draft endpoint.
6. **Two staff UIs** with two data models, fonts, icon sets and style systems; vanilla-JS monoliths that re-render via `innerHTML`; console tests slice `index.html` source text. Fix: one app shell, Inbox as home, admin as routes, shared ES modules.
7. **MCP servers double as the internal RPC bus**, so the prompt-injectable model can call bulk `list_inbox_tickets` (pages every ticket). Fix: an agent-facing mount with the per-ticket tools only.
8. **Prompt monolith.** `processor/hermes_runner/prompt.py` (480 lines) mixes platform contract, merchant facts ("Thanks, Buttons Bebe", Toms River/Lakewood) and test-scenario rules; ticket fields precede static rules, defeating prompt caching. SOUL/skills are mirrored to the VPS by hand and Hermes itself is hot-patched outside CD.
9. **Learning loop governance.** Full-weight auto-promotion, no review queue, no TTL, no provenance, no erasure; customer text stored verbatim is a persistent prompt-injection channel; masking is regex-only.
10. **Unversioned schema.** 13 tables, DDL across 5 modules, no FKs, startup `ALTER TABLE`.
11. **Durability.** Scheduled backups cover 2 SQLite files on the same host; KB edits, `learned/` and WhatsApp auth are backed up nowhere; the only alert path is Baileys on the same box.
12. **Dead weight.** 242 retired files / 36.8k lines tracked (26%): `gorgias-webhook/`, `teddy/`, `qa_v3/`, `qa-run/`, `kb-editor/`; helpdesk-agent (8.8k lines) shipped with no service; `shopify/shopify.py` has no production importer; 14 historical root docs; 103 local branches + 225 checkpoint refs. Churn shows Inbox 1 was built (top UI churn) then deleted; `verify_release.sh` is itself a churn hotspot.

## 5. Keep (port these)

- Durable human send intents: operation IDs, recipient re-check, never auto-resend, read-only reconcile (`webhook/src/bb_webhook/send_intents.py`, `console_actions.py`).
- Token-authenticated, bounded model-output parsing + marker neutralisation (`processor/hermes_runner/extract.py`); `final_review_result` as an escalate-only pure function.
- Credential isolation: allow-listed LLM child env, read-only tool annotations, credential-free Inbox read API, strict CSP, hardened `helpdesk-inbox2.service` as the unit template.
- Atomic intake transaction; attempt journal with revision hashes; fail-closed freshness.
- KB index safety (staged build, parity validation, last-known-good restore) and the `SearchOutcome` health model.
- `intake/message_content.py`; the deterministic classifier as a safety net.
- CD integrity chain (verified SHA, restricted SSH, monotonic generation, scoped readiness + rollback).
- 48 + 10 scenario eval discipline and the `demo/` adversarial fake stack.

## 6. Market (summary of the research agent; sources in the session)

- Autonomous resolutions sell for $0.75–2.00; drafting/assist for $0.25–0.40 per ticket or $29–50/agent. Drafts alone are bundled free by Help Scout and Shopify Inbox — sell measured accuracy, safety and a path to autopilot.
- Closest competitor: **Macha** (drafts as Gorgias internal notes → autopilot, ~$0.40/ticket). Overlays on Gorgias: Yuma, Siena, eesel.
- LLM cost on gpt-6-luna ≈ $0.006–0.014 per draft → 92–97% LLM margin at $0.30/ticket. Avoid per-seat pricing; onboarding labour is the real cost.
- Gorgias apps: OAuth2, 80 req/20 s per account, HTTP-integration webhooks are unsigned with a 5 s timeout and auto-disable after 500 failures.
- Shopify App Store: Billing API mandatory, GDPR webhooks, Level-2 protected data, 0% revenue share to $1M lifetime.

## 7. Recommended path

**Strategy:** strangler. New multi-tenant core; port the Keep modules; Buttons Bebe migrates as tenant #1. Retrofitting tenancy into this VPS tree touches nearly every file for less result.

**Wedge:** human-in-the-loop "safe drafts" copilot inside Gorgias for Shopify brands where a wrong answer is costly. Starter $149 / 500 drafts · Growth $349 / 1,500 · Scale $699 / 3,500 · $0.20 overage. Sell 5–10 brands directly → Gorgias App Store → Shopify listing after ~10 paying. Skip standalone helpdesk and Zendesk for now.
