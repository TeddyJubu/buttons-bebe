## Policy and agent action — identifying a gift sender

Customer received a gift package and wants to know who sent it.

Agent action:
Locate order by recipient name/address/tracking.
Check for gift note.
If note exists, share the note/sender info if appropriate.
If no note exists, check purchaser details.
Use privacy judgment before revealing purchaser information.
Escalate if unsure.

## Customer response

Ask for an invoice or tracking identifier only if none was supplied. If staff must check the gift note or permission to disclose sender details, hold the draft as Needs staff input and name that exact privacy check in staff_next_step. Never claim a lookup is underway or disclose purchaser information from a guess.
